# 入稿まえチェッカー

同人誌の原稿データ(PNG・JPEG・PSD・PDF)を入稿前にチェックする無料のWebツールです。

https://uuhai0625.github.io/nyuko-checker/

- 原稿ファイルはブラウザの中だけで読みます。外部に送信・保存しません(アクセス解析にGoogle Analyticsを使っていますが、ファイルの中身・ファイル名・チェック結果は送りません)
- 判定は目安です。入稿の前には、使う印刷所の入稿ガイドで最終確認してください
- PDFの読み込みに [pdf-lib](https://github.com/Hopding/pdf-lib)(MIT License)を使っています。ライセンスは `vendor/pdf-lib-LICENSE.txt`
